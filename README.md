#  Tribute Page - Quaid-e-Azam Muhammad Ali Jinnah

##  About the Project
This is a responsive tribute webpage built using **HTML and CSS**.  
It highlights the life and achievements of **Quaid-e-Azam Muhammad Ali Jinnah**, the founder of Pakistan.

The project was created as a practice exercise to strengthen my frontend development skills, especially in semantic HTML and CSS layout design.
##  Built With
- HTML5  
- CSS3 
##  Features
- Semantic HTML structure  
- Responsive image layout  
- Timeline of historical events  
- Styled quote section  
- External Wikipedia link  
- Clean and simple UI design  
##  What I Learned
- How to structure a webpage using semantic tags (`main`, `figure`, `figcaption`)  
- CSS layout and styling basics  
- Responsive image handling  
- Git & GitHub project deployment
